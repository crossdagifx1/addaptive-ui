Quickstart Guide

Integrate AUI into any web application or site in under 5 minutes with zero layout shifts and complete safety guarantees.

1. Installation

Install the AUI CLI globally or run it directly via npx:

npm install -g @aui/cli
# Or run with npx:
npx aui init

2. Initialize Your Site

Run aui init inside your web project root. This creates aui.config.json and a validated blueprint.json starter.

3. Embed Client Layer

Add the drop-in embed script to your HTML head:

<script src="https://addaptive-ui.vercel.app/aui.js"
        data-aui-signing-key="your_hmac_secret"
        async></script>

9-Stage Security Validation Engine

Every generated candidate blueprint must pass through nine zero-bypass validation stages before it can ever be displayed to a visitor:

  • Stage 1 (Schema): Strict Zod & JSON-Schema syntax enforcement.
  • Stage 2 (Component): AST verification against the registered component catalogue.
  • Stage 3 (Permission): Section-level modification access control.
  • Stage 4 (Locked Zone): Absolute immutability guard for pricing tables and legal terms.
  • Stage 5 (Content Policy): Rejection of prompt injections, homoglyphs, and banned phrases.
  • Stage 6 (Link Action): Strict domain and protocol whitelist enforcement.
  • Stage 7 (Accessibility): WCAG contrast and ARIA attribute verification.
  • Stage 8 (Size Budget): Payload size upper bounds (< 64 KB).
  • Stage 9 (Diff Size): Maximum permissible UI delta per session (< 40%).

SpendGovernor Cost Controls

Protect your AI budget with automated spending caps, threshold warnings, and graceful degradation:

import { SpendGovernor } from '@aui/storage';

const governor = new SpendGovernor({
  monthlyCapUsd: 500,
  warningThresholdPercent: 80,
  onAutoPause: () => console.log('Monthly cap hit! Auto-paused.')
});
